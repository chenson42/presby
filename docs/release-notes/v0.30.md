## 0.30.0 — 2026-10-05

### A form can no longer lose or rewrite what you entered while the page was still loading

**Background:** On a slow connection, a page's form can appear on screen a few seconds before the code that runs it has finished arriving. During that gap, a congregation picked in the presbytery's annual-statistics form could be silently switched back to a different congregation the moment the page finished loading — and the statistics were then saved against the wrong congregation, with a "saved" message and nothing to show anything had gone wrong. Testing on a production build over a throttled connection reproduced it every time. Every other form built the same way (people, officers, groups, events, staff, oversight, per capita, and the public statistics filing page) had the same gap.

**Changes:**
- Every form now stays visibly disabled — greyed-out fields and a greyed-out button, labels still fully readable — until the page is fully ready, and then enables itself. Nothing you do before that moment can be lost or rewritten, because nothing can be entered before that moment.
- On a fast connection the disabled state lasts a fraction of a second and is not noticeable. On a very slow connection (a phone on a poor signal) a form may look disabled for several seconds before it enables; that is the page finishing loading, not an error. Forms that edit an existing record may also show empty fields until that moment; the saved values appear as soon as the form enables. Shortening that wait and showing saved values sooner are tracked follow-ups.
- The statistics form's year and congregation controls, and the other presbytery forms, now carry an automated browser test that loads the page with its code deliberately held back, proves the form is disabled, releases the code, and then checks the saved record names the congregation that was actually chosen. The test also runs against a production build, not only the development server.
- A project check now refuses any new form that is not protected the same way.
