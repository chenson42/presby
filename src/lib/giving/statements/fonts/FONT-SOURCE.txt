Fonts embedded in year-end contribution statements (DECISION-174, obligation 3)
==============================================================================

Why a committed font: donor names arrive from Stripe and from recorders in any
script, and PDFKit's built-in standard-14 fonts (Helvetica and friends) are
WinAnsi only - a Vietnamese or Polish name would print as missing glyphs.

Family:   Noto Sans (Regular, Bold), Version 2.015, unhinted TrueType
          (hinting is a screen-rasterizer aid; PDFKit embeds a subset either way)
Licence:  SIL Open Font License 1.1 - OFL.txt in this directory, verbatim from
          https://raw.githubusercontent.com/notofonts/latin-greek-cyrillic/main/OFL.txt
Coverage: Basic Latin, Latin-1, Latin Extended-A/-B, Latin Extended Additional
          (all Vietnamese precomposed letters), the dong sign, Greek, Cyrillic.
          Verified glyph by glyph with fontkit when committed (Batch 5a).

The font files are unmodified. OFL 1.1 permits embedding in documents and
redistribution with the licence; the Reserved Font Name clause does not apply
because the files are not modified or renamed.

Tracing: next.config.ts `outputFileTracingIncludes` copies this directory (and
PDFKit's own AFM data) into the serverless function for the statement routes;
`serverExternalPackages: ["pdfkit"]` keeps PDFKit out of the bundle so its
`__dirname`-relative reads resolve. Docs: docs/work-log/2026-10-15-online-giving.md,
"Batch 5a".
