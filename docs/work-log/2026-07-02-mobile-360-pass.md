## Phase 4 — Implementation (UI) — 2026-07-02

**Owner:** ux-developer
**Status:** complete

### Summary

Ran a 360px Playwright screenshot pass against a dev server on port 3100 using
saved storageState for both member and admin users. Found two genuine breakages
(both layout files using `grid-cols-[220px_1fr]` which left only 140px content
width at 360px), one tight-but-fixable nav crowding case (admin user seeing
Account+Admin+Sign out crammed against the brand), and confirmed four known
candidates were non-issues. Fixed with class-attribute-only Tailwind responsive
additions. Typecheck, lint, and all 336 unit tests pass.

### Findings table

| Surface | Issue | Fix |
|---------|-------|-----|
| `(account)/layout.tsx` | `grid-cols-[220px_1fr]` at 360px leaves sidebar=220px, content=140px — severely cramped | Changed to `grid-cols-1 md:grid-cols-[220px_1fr]`; aside gets `border-b md:border-b-0 md:border-r` so it stacks on top on mobile |
| `(admin)/admin/layout.tsx` | Same `grid-cols-[220px_1fr]` pattern — same 140px content breakage | Same fix as account layout |
| `components/shared/global-nav.tsx` | Admin user (Account+Admin+Sign out nav) — gap between brand and first nav link was ~13px at 312px effective width, visually crowded | Reduced base padding `px-6` → `px-4 sm:px-6`; content width at 360px rises from 312px to 328px |
| Home heading (`text-3xl`) | "Welcome, Local Member." wraps to 2 lines — **intentional**, not a breakage | OK — no change needed |
| Quick links (home) | Already uses `flex flex-wrap gap-3` — no overflow | OK — no change needed |
| Feedback prompt card | `p-5` padding; card content fits cleanly at 312px | OK — no change needed |
| Global nav (member-only user) | "Account Sign out" — fits at 360px with comfortable gap | OK — no change needed |
| Admin feedback table | Wide data table; `overflow-x-auto` already present; layout fix (sidebar → stacked) gives table full 360px width; Submitted+Member columns visible, Message+Status scroll right | OK — correct scrollable-table behavior |
