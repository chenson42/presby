## 0.43.0 — 2026-10-25

### Feature: The platform admin area opens on a dashboard, with a grouped menu

**Value:** The platform admin area used to open on a grid of tiles and a long side list of links, the same for everyone. It now opens on a dashboard that says where something is waiting for you, with organizations first, and a shorter menu that shows only the tools you can open. This is the first of four steps; the page for working inside one organization comes in the next.

#### What's New

- **A dashboard at `/admin`.** It starts with a box to find an organization and a "New organization" button, then cards for what is waiting, grouped as Organizations, Support, and Access and settings. A line near the top says when the page was last updated. Each card is a single link to the page where you act on it.
- **Each card says what it found.** A card with something waiting is marked "Needs attention" with a warning symbol and those words, so it does not rely on colour. A card with nothing to do says "Nothing waiting."
- **A card that cannot load says so.** It shows "We can't load this right now." with a "Try again" link, and never shows a zero in its place. The other cards still load.
- **You see only the cards you have permission for.** If you can open the admin area but hold no tool permissions, you see the same short "no access to any admin tools yet" message as before.
- **Recent operator changes.** A short list of access, feature-flag and account changes made by platform operators, such as a role assigned, a flag changed, an account deactivated, an organization's founding administrator or treasurer removed, or an invitation an operator sent to themselves. It is there to be read; it does not block or approve anything.
- **A grouped menu.** Dashboard, then Organizations, Support, Access and settings, and Content, with Release notes and Design system under Reference at the bottom. It lists only the tools you can open, marks the page you are on, and Feedback now has an entry.
- **A phone menu.** On a phone, a "Menu" button opens the same list in a panel. Choosing a page closes it.
- **The same account menu as the rest of the app.** The admin header now has the avatar menu, and signing out is there instead of in a separate button.
- **A calmer error page.** If something goes wrong on an admin page, you see "We couldn't load this page" instead of a raw error.
- **Clearer wording** on the organizations list and a few of its neighbours, where the old text described a different tool.

#### What is not here yet

- The page for working inside one organization, and the cards for organizations waiting for a first administrator and for invitations, come in the next step.
- The two-factor card counts accounts whose organization requires two-factor sign-in but who have not set it up. Working out who is required uses the congregation's people records, so it is not a platform-only figure.
- A few older admin pages, such as Users and Release notes, keep their old layout for now and are brought into line in the last step. The Release notes page is a little wider than a phone screen.
- Design system is under Reference for everyone who can open the admin area.
