## 0.20.0 — 2026-08-27

### Feature: Presbytery congregation oversight, statistics, and per-capita billing

**Value:** A presbytery's stated clerk can now record their own judgment about a member congregation — its viability, its buildings and insurance — without waiting on anything from the congregation itself, and can see a single, honest picture of every congregation's statistics whether the presbytery entered the numbers or the congregation reported them.

#### What's New

- A new Congregation Oversight tool records viability and property assessments for any member congregation, whether or not it's a live tenant on the platform.
- A new Statistics & Per Capita tool tracks each congregation's annual numbers — with every figure clearly labeled as either "presbytery estimate" or "congregation reported," so nothing is mistaken for more authoritative than it actually is.
- Per-capita billing derives directly from those statistics: set a rate, generate the year's bills, and each bill locks in the count it was calculated from, so a later correction can never quietly move a bill that's already gone out.
- Behind the scenes, this is the platform's first mechanism for a congregation to publish its own record up to its presbytery — the technical foundation a future release will build a congregation-side publishing tool on top of.
- A presbytery or synod with no public website now shows a simple "sign in to the portal" page instead of a dead link.

#### Permissions

| Feature key | Required for |
|-------------|--------------|
| `congregation_oversight.manage` | Recording viability and property assessments |
| `statistics.manage` | Entering or viewing congregation statistics |
| `per_capita.manage` | Setting rates, generating bills, recording payments |

#### New Routes

- `GET /o/<slug>/admin/oversight` — congregation oversight records
- `GET /o/<slug>/admin/reports` — statistics and per-capita billing

---

### Feature: A merged home page and a redesigned admin portal

**Value:** Signing in used to land you on a chooser page, with a separate, differently-designed page holding your account's other information. Administrators saw every admin tool listed, whether or not they could actually use it.

#### What's New

- Your home page after signing in now shows your organizations, the platform tools you have access to, and what's new — all in one place, in the same visit.
- The admin dashboard now shows each administrator only the tools they're actually entitled to use, organized into labeled groups — no more clicking a tool only to be told you can't use it.
- The public home page now actually describes PresbyPortal, including what it does today and who it's for.

---

### Announcement: The project is named PresbyPortal

PresbyPortal (`presbyportal.org`) is the platform's name going forward. Public-facing pages now use it; internal database and code naming will follow in a later, dedicated release.
