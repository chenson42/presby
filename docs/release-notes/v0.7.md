## 0.7.0 — 2026-08-09

### Infrastructure: Enforcement Batch (Fable external review)

**Background:** The 2026-08-09 external review by the Fable model (`docs/reviews/2026-08-09-fable-external-review.md`) found one pattern across the whole process stack: *the process knows things it doesn't enforce*. The repo's own retrospective had named the running-server e2e suite the sole defense for its dominant bug class — yet e2e never ran in CI — and the most drift-prone conventions (cadence check, pre-push discipline, TODO reconciliation) lived only as prose. This release moves the cheap-to-mechanize rules into CI and hooks.

**Changes:**

- **E2E in CI** — new `E2E` workflow creates an ephemeral Neon branch per run, pushes schema + seeds, runs the full Playwright suite against a real dev server, and deletes the branch. Secret-gated (`NEON_API_KEY` + `NEON_PROJECT_ID`): forks without secrets skip cleanly. All other credentials are generated per-run. `playwright.config.ts` now has a `webServer` block — locally, e2e reuses a running dev server or starts one itself.
- **Pre-push gate** — `/pre-push` stamps a HEAD-keyed marker after a clean "Ready to push: yes"; a PreToolUse hook blocks any in-session `git push` without a fresh marker (Workflow Rule 5, previously prose-only). Committing after the stamp invalidates the marker.
- **Cadence-check hook** — third SessionStart hook (harvested from the huddleup.health fork) computes overdue periodic reviews from `docs/reviews/log.md` mechanically, replacing the manual six-step session-start ritual.
- **`Work-Log:` commit trailer** — required on `feat:`/`fix:` commits, format-checked on all; joins every commit to its pipeline work-log so escape-rate tooling can map commits → pipelines without hand-reconstruction.
- **CI hardening** — both tripwires run (`check:sql-date` was missing), `npm audit` on production deps (high+; advisory until the next-auth beta.32 upgrade clears its @auth/core advisories through an e2e-gated pipeline), and a commit-grammar job re-validates every PR commit with the same validator as the local hook (closes the GitHub-web-edit bypass).
- **Dependency patch** — Next.js 16.2.10 → 16.3.0 (clears the bundled-postcss XSS/path-traversal advisories and two Next.js highs), sharp → 0.35.3 (libvips CVEs). Verified: build + 425 unit tests + full 48/48 e2e suite against a running dev server.
- **Dependabot** — weekly npm updates (grouped minor/patch; majors and the pinned NextAuth beta stay with the monthly dependencies review), monthly actions updates.
- **`AGENTS.md`** — cross-tool shim pointing non-Claude agents (Cursor, Codex, Jules) at CLAUDE.md and the must-honor rules.
- **Opt-in Claude PR review** — secret-gated workflow (`ANTHROPIC_API_KEY`) adds an independent cold-context reviewer at the PR boundary; PR-open/ready-only triggers with concurrency-cancel to keep token spend minimal (nonprofit posture).
- **`/pre-push`** also gained a deck-staleness housekeeping check (slides.md changed without slides.pdf).
