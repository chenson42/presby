Two-factor sign-in asks for a six-digit code from an app on your phone, called an authenticator app, as well as your password. You link the app once. At the end PresbyPortal gives you ten recovery codes to keep. This page covers both, and what to do when you need new codes.

## Where to set it up

Some people are taken to the set-up page when they sign in. [Who is asked for a code](/help/who-is-asked-for-a-code) says who. Anyone can also open it on their own: select your initials at the top right, choose "Account", and in the "Two-factor authentication" section select "Set up two-factor authentication". The section shows "Not set up" until you have finished, and "Active" afterwards. See [Your account](/help/your-account).

## Linking your authenticator app

The set-up page is headed "Enroll in two-factor authentication".

1. Install an authenticator app on your phone if you do not have one. The page names Google Authenticator, 1Password and Authy.
2. In the app, scan the QR code on the page. If you cannot scan it, open "Can't scan? Enter manually" and type the key it shows.
3. Under "Enter the 6-digit code from your app", type the six digits the app shows for PresbyPortal. PresbyPortal checks the code as soon as you type the sixth digit. If nothing happens, select "Confirm enrollment".

The QR code is good for 10 minutes. If it runs out, reload the page for a new one. If a code is refused, the page says "That code did not match. Try again." Wait for the app to show the next code and try again.

## Your recovery codes

When the code matches, the page changes. It is headed "Two-factor authentication enabled" and says that your authenticator app is now linked. Under "Recovery codes — save these now" it shows ten codes. Each code lets you sign in once if you lose your authenticator.

**Save the codes before you leave the page.** They are shown only once. If you reload the page or leave it, PresbyPortal cannot show them again. Write them down, take a screenshot, or copy them into a place you trust, such as a password manager. Do not keep them where someone else can read them.

Select "Continue" when you have saved them. If you opened the set-up page on the way to somewhere, "Continue" takes you there, and you are usually not asked for another code. Sometimes the page adds that you may be asked for a code from your app once more before you reach your destination. If so, enter it as usual. See [Using your code to sign in](/help/using-your-code).

## Coming back to the page later

Open "Account", then "Manage / regenerate codes". The page is headed "Two-factor authentication". It says when you enrolled and how many recovery codes are unused, for example "10 unused codes remaining (of 10 total)". It cannot show the codes themselves.

## Making new recovery codes

Make a new set if you have used most of your codes, lost the list, or think someone saw it.

1. First confirm that it is you. If you have not entered a code in this sign-in, the page says "To make new recovery codes, first confirm it's you with your authenticator app or a recovery code." Select "Confirm it's you", enter a code, and you come back to this page. If you cannot enter a code, you cannot make new codes.
2. Select "Regenerate recovery codes". The page says that this replaces every existing code and that the new set is shown once.
3. The page shows "New recovery codes — save these now" with ten new codes. Your old codes stop working. Each new code can be used once.

As with the first set, the new codes are not shown again if you reload or leave the page.

## If something goes wrong

- "Enrollment session expired. Reload the page to start over." The set-up page was open for more than 10 minutes. Reload the page and scan the new QR code.
- "Two-factor authentication is already set up on this account, possibly in another tab. Reload this page." Reload. If the page now says you enrolled on a date, setup is finished. If you do not have the codes from the first time, make a new set.
- "Something went wrong and we could not confirm your code. Reload this page to see whether setup finished." Reload the page. If it says you enrolled, setup finished, and you can make a new set of codes to see them.
- "Confirm it's you with your authenticator app or a recovery code first. Reload this page to see how." You pressed "Regenerate recovery codes" before confirming in this sign-in. Reload and use "Confirm it's you".

If you lose your phone and your recovery codes: PresbyPortal has no button that resets two-factor sign-in for you. Only the PresbyPortal team can reset it. Ask a church administrator to send the team a support ticket for you. See [Getting help](/help/getting-help).

If you are the only administrator and have no one to ask, [write to the PresbyPortal team](/help/contact) and choose "I can't sign in or I lost my codes" under "What is this about?". A message cannot reset anything by itself. The team uses the email address on your account to check with you, and that address may not be the one you type in the form.
