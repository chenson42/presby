## 0.58.0 — 2026-11-16

### Enhancement: Website footer contact and identity

**Value:** An organization's website footer can now show a full postal address, say what the organization is, link to its contact page and carry the details search engines read, which is what nonprofit verification checks ask for.

**Changes:**
- The address on an organization's profile is now entered on several lines, as on an envelope (up to six). The website footer and the portal footer show it line by line; "Get directions" still opens the whole address in a map. An address already entered on one line shows as before.
- Website footers (presby-site-kit v4.5.0) can add, from the website's own content: a line under the logo (for example the denomination), up to four footer links such as "Contact us", and the organization's name in the copyright line in place of "All rights reserved".
- A website can add organization details for search engines on its home page: the name, address and phone from PresbyPortal, plus a legal name, EIN, nonprofit status, parent organization and other web addresses from the website's content. The EIN is not shown on the page, but anyone can read it in the page's source.
- Every website that does not use the new options looks exactly as it did.

**Help:** /help/your-congregations-website (one paragraph on who changes the footer).
