Some accounts are asked for a six-digit code each time they sign in. The code comes from an authenticator app on your phone. This page covers the "Two-factor authentication" page you see after you enter your password. To link the app the first time, see [Setting up two-factor sign-in](/help/setting-up-two-factor).

Whether you are asked for a code depends on your account, your role and your congregation. See [Who is asked for a code](/help/who-is-asked-for-a-code).

## Entering your code

1. Sign in with your email and password, or with Google.
2. On the "Two-factor authentication" page, open your authenticator app and find the six-digit code for PresbyPortal.
3. Type the six digits into the six boxes. PresbyPortal checks the code as soon as you type the sixth digit.
4. If nothing happens, select "Verify".

When the code matches, you go on to the page you were heading for, which is usually your congregation's page.

![The six boxes for the code from your authenticator app, with the Verify button and the recovery code link.](shot:totp-boxes)

The code in the app changes every 30 seconds. If a code is refused, wait for the next one and try again. The page says "That code didn't match. Try again, or use a recovery code." when a code is refused.

## Using a recovery code

If you cannot use your phone and you have recovery codes, you can use one instead.

1. Select "Use a recovery code instead".
2. Type one recovery code in the "Recovery code" box. A recovery code looks like ABCD-EFGH. Capital or small letters both work, and the dash is optional.
3. Select "Verify".

Each recovery code works once. If a recovery code is refused, the page goes back to the six boxes and shows the same message. To go back to the six boxes yourself, select "Use my authenticator app instead".

## If you lose your phone and your codes

PresbyPortal has no button that resets two-factor sign-in for you. Only the PresbyPortal team can reset it. Ask a church administrator to send the team a support ticket for you. See [Getting help](/help/getting-help).

If you are the only administrator and have no one to ask, [write to the PresbyPortal team](/help/contact) and choose "I can't sign in or I lost my codes" under "What is this about?". A message cannot reset anything by itself. The team uses the email address on your account to check with you, and that address may not be the one you type in the form.
